Node Functions

Four functions. All on-chain.

Nodes don't run AI. They run the protocol layer that lets every agent be discovered, attested, metered, and routed — lightweight, deterministic, verifiable.

01
Attestation

Protocol compliance attestation

When an agent produces an output, a randomly selected subset of nodes independently attests to protocol-level properties — SLA latency, schema conformance, delivery, size bounds. Multi-node attestation recorded on-chain.

Random sampling · signed attestations · tamper-evident
02
Metering

Activity metering & accounting

Independent metering of Forge and protocol transaction volume per epoch. Multiple nodes produce the same count — discrepancies detectable on-chain. The Activity Pool distributes fees proportional to verified uptime.

Per-epoch counts · verifiable on-chain · cross-node consensus
03
Registry

Registry & discovery service

Each node maintains a synchronised local copy of the agent registry — metadata only, not models. Queries from Forge or external integrations are served by the node network as a distributed index.

Local replica · distributed queries · uptime-gated
04
Routing

OAMS message routing

In multi-agent workflows, messages route through nodes via the OAMS protocol. Each node validates schema, hashes the payload, and attests integrity at every hop — preventing tampering across the chain.

OAMS schema · per-hop attestation · end-to-end integrity

FAQ

Common questions.

The most-asked. The full FAQ has the rest.

Technical requirements to run a node?→

No GPU. The client runs on a laptop or modest VPS. Nodes attest, meter, route, and serve registry queries at the protocol layer — no inference required.
What chain is the node minted on?→

ERC-721 on Arbitrum or BNB Smart Chain — buyer chooses at purchase. $OPRN settles on Arbitrum.
Can I sell my node?→

Yes — after a 6-month transfer lock from purchase. Emission rights are NFT-bound, so they follow the token on transfer along with accrued vOP and active vesting entries.
How are rewards generated?→

Four streams: daily base emissions for 4 years, quarterly performance bonuses, a share of all network usage fees, and on-chain referral attribution.
When does the sale end?→

Sale runs open-ended; the team pauses ahead of TGE. Token holders then vote whether to resume the sale or burn unsold node allocations — burned allocations redistribute to existing holders.
What is vOP?→

vOP is virtual $OPRN — accrued daily, claimable any time. At claim, choose a vesting tier (30 / 120 / 180 / 360 days) with linear unlock. Forfeitures from accelerated claims fund bonuses for patient operators.
